Introduction
This document describes the research carried out to support the redesigning of the Panorama Pet Shop website. 
The goal of this research was to collect meaningful content for each the site’s pages, which includes the Home, Products, About Us, Services, and Contact Us pages. 
The gathered information will serve as the foundation for building an accessible and easy-to-use website using HTML, CSS, and JavaScript.

3. Content Research and Sourcing
Organization Research
Organization’s Website
The official Panorama Pet Shop website was used as the main source for researching information about the organization and its product. 
The website was used to identify the types of products sold, product categories and general information about the business.
The researched information was used to plan the pages:
•	Home
•	Products
•	About Us
•	Services
•	Contact Us





Product Content
Product information was researched from the Panorama Pet Shop website. 
The website contains products for different types of pets, including dogs, cats, fish, birds, reptiles and small animals.
It also includes categories such as accessories, bird food, fish products and other pet supplies.
This research was used to organize the Products page into the following categories:
•	Dogs
•	Cats
•	Birds
•	Fish
•	Reptiles
•	Small Animals
•	Accessories
Additional product information and descriptions will be written in my own words where required.

Images
The images used for the redesigned Panorama Pet Shop website will be sourced from the official Panorama Pet Shop website. 
Product images will be used on the Products page, while an image of the Panorama Pet Shop store will be used on the About Us page. 
A separate image featuring different pets for the homepage will be sourced from Shutterstock. 
The images were selected based on their relevance to the content and purpose of each webpage.
The source of each image will be recorded so that the original source can be identified.

Social Media Research
The Panorama Pet Shop Instagram profile page was reviewed. 
The page mostly features updates about temporary sales and weekly deals. 
These dynamic sales sections will be excluded for now to keep the website layout simple, clean, and easy to build using permanent information from the official website.



Icons
Icons used on the website will be sourced from Flaticon.
The icons may be used for:
•	Phone
•	Email
•	Location
•	Social media
•	Navigation
•	Other interface elements


Fonts
The fonts used for the website will be sourced from Google Fonts. The selected fonts will be used consistently throughout the website to maintain a clear and readable design.

Original Content
Some content will be created specifically for the redesigned Panorama Pet Shop website. This includes:
•	Homepage Introduction
•	About us content
•	Service descriptions
•	Short product description
•	Button labels
•	Other supporting website text
The original content will be written based on the research conducted on Panorama Pet Shop.


4. Website Structure and Planning
4.1 Sitemap
A visual sitemap detailing how pages link together was designed using a cloud-based planning tool (Lucid Software, n.d.). 
The final exported image file is saved inside Content-Research/sitemap/ subfolder.

4.3 File and Folder Structure:
A clean, modular directory structure was mapped out to separate assets from core HTML code. 
This layout keeps images, styling sheets, and scripts organized and can be reviewed inside the Content-Research/File&Folder-Structure-image planning folder.
